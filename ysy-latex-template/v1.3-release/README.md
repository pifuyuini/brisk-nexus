# 基于YsyClass样式的ysy-latex模版v1.3发行版

2025年6月1日  
原则上，v1.3版本仍为测试版本，**不公开**。为了方便测试人员，制作了这个发行版，并编写了几个demo和以下极简使用指南。

---

## 极简使用指南（草稿）

### 仓库v1.3-release介绍

1. `demo`里有几个演示（基本笔记、近物报告、基物报告和学术论文），旨在展示各个模式的使用效果。
2. `template`是作为一个**标准的项目模版**。
3. `ysy-latex`则是**YsyClass样式**的主要内容，如果你想在自己的项目中导入它，请将这个文件夹复制到你的项目中，参考几个演示来使用它。

### `template`用法

1. 复制整个文件夹，然后将名称改为你的项目名称。
2. 打开其中的`.py`文件，运行它；然后你可以进行样式的选择——如果你第一次使用，推荐使用颜色主题“SkyRelax”并勾选上所有内容；生成`console.tex`文件。
3. 接下来进入`console.tex`文件，你需要基于你选取的模式，填上“个人信息”；特别的，某些模式下有封面插图，默认情况下请填上“cover_img”；当然，你有自己的插图的话，请将它放在`images`文件夹中（你后面要插入的所有图片我都建议放进这个文件夹里）；填写好后，你就可以自由编辑了。
4. `console.tex`是作为内容如何呈现和风格的控制文件，你的内容主要放在`contents/main.tex`里；**内容和样式分离可以使得你更专注于内容的创作（也许吧）**。
5. `contents/appendix.tex`和`contents/ref.tex`的用法请参考演示。

### 特色介绍

好看的颜色主题、颜色盒子、颜色文字，便捷的中英文切换，便捷的模版切换，也许能提高效率的模版结构与封装。
